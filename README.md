# 永恒之塔2 · 国际服简繁汉化工具

把《永恒之塔2》(AION 2) 国际服的**英文 / 日文**文本，替换成**简体 / 繁体**中文。

- 当前版本：**v0.0.1**
- 适用平台：Windows 10 / 11
- 完全免费开源，**严禁任何形式的倒卖牟利**

## 支持的语言组合

| 入口 | 游戏内语言需设为 | 汉化结果 |
| --- | --- | --- |
| 英文入口 | English | 简体中文 / 繁体中文 |
| 日文入口 | 日本語 | 简体中文 / 繁体中文 |

两个入口**互斥**：安装时会先移除另一个入口的文件，日志里会逐条显示移除了什么。

> 工具只替换客户端本地化文本文件，不改 pak、不改字体、不改游戏语言设置。

## 使用步骤

1. 进游戏确认当前语言：
   - 用**英文入口** → 游戏内语言必须是 **English**
   - 用**日文入口** → 游戏内语言必须是 **日本語**
2. 完全退出游戏和启动器（Steam / PURPLE）。
3. 双击 `1-图形版-双击启动.exe`。
4. 在界面上选择汉化语言（默认英文入口）。
5. 阅读风险说明，滚动到底并等待 3 秒，勾选后再点「一键应用简体」或「一键应用繁体」。
6. 直接启动游戏，进游戏就是中文。

想换简体 / 繁体：入口不用改，直接点另一个「一键应用」按钮。
想还原官方：点「一键还原」，或运行 `3-窗口版-还原官方.bat`。

## 常见问题

**Q：装完进游戏还是英文 / 日文？**
九成是入口选错了。英文入口要求游戏语言 English；日文入口要求 日本語。改完语言要完全退出游戏（含启动器）再重新进。

**Q：之前装过另一个入口，现在想换？**
直接选新入口点「一键应用」即可，工具会先删掉旧入口的文件，日志里逐条显示移除了什么。

**Q：怎么还原？**
运行 `3-窗口版-还原官方.bat`，或图形版点「一键还原」。删掉汉化文件即回到官方原版。

**Q：提示文件被占用 / 写入失败？**
游戏或启动器还在后台。请完全退出后重试；若仍失败，可尝试以管理员身份运行。

**Q：杀毒软件报毒？**
本工具由 PowerShell 脚本 + .NET 小程序组成，常被误报，加白名单即可。

**Q：装完出问题怎么办？**
运行 `4-出问题点这个-生成诊断.bat`，把生成的报告发给作者。
